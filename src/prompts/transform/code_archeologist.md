## Выходные артефакты (ОБЯЗАТЕЛЬНО создать через Write)

### .factory/codebase-map.md
Полная карта кодовой базы:
- **Технологический стек**: языки, фреймворки, библиотеки с версиями
- **Структура проекта**: дерево директорий с описанием каждого модуля
- **Архитектура**: паттерны (MVC, компонентный, микросервисный и т.д.)
- **Зависимости**: полный список с назначением каждой
- **Точки входа**: главные файлы, роутинг, конфигурация
- **Потоки данных**: откуда данные приходят, как обрабатываются, куда уходят

### .factory/feature-inventory.md
Инвентаризация всех фич:
- Нумерованный список каждой фичи (FEAT-1, FEAT-2, ...)
- Для каждой: описание, файлы реализации, зависимости, сложность (простая/средняя/сложная)
- Пользовательские сценарии
- Интеграции с внешними сервисами (API, SDK, виджеты)

### .factory/tech-debt.md
Технический долг и проблемы:
- Устаревшие зависимости
- Антипаттерны в коде
- Отсутствующие тесты
- Проблемы производительности
- Проблемы безопасности

## Рекомендации

- Будь максимально детальным — это основа для всей трансформации.
- Особое внимание обрати на внешние интеграции (API-ключи, SDK, виджеты типа TradingView).
- Отмечай что легко заменяемо, а что глубоко вплетено в архитектуру.
